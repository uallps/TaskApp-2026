# Experimento de interfaces SwiftUI / SwiftCrossUI

Esta rama se deriva de `sesion-04` y contiene la comparativa de la
aplicación de tareas en SwiftUI (macOS) y SwiftCrossUI (macOS/AppKit,
Linux/GTK4).

El ejemplo independiente vive en
[taskapp-swiftcrossui](taskapp-swiftcrossui/README.md) y contiene código,
pruebas de la lógica compartida y capturas reales de las tres ventanas.

**No corresponde a una sesión numerada del temario**: se mantiene separado
para no alterar las etiquetas pedagógicas `sesion-01`…`sesion-05`.
